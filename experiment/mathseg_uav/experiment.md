## 4. 为什么 M1 没有提升：实际诊断

已核对运行配置、脚本以及实际 checkpoint：未发现加载错变体、漏优化调制参数或划分不一致的问题。M1 比 M0 增加 320 个参数；调制 weight/bias 的 Adam step 均为 159600，权重非零、优化器动量非零，两组共有参数也并非同一份数值。

在同一个 M1 best.pt 上，仅改变推理中的调制路径，对完整 699 张验证图重新评估：

| 干预 | Val mIoU (%) | 相对正常 M1 改变预测的有效像素 (%) |
| --- | ---: | ---: |
| 正常 M1 | 76.789540 | 0 |
| 完全旁路调制模块 | 76.791874 | 0.033255 |
| 各先验通道替换为每张图的空间均值 | 76.790021 | 0.016213 |
| 先验置零，保留调制卷积偏置 | 76.790865 | 0.029243 |

正常路径精确复现原最佳验证分数。关闭调制和移除空间信息几乎不影响预测，说明该 checkpoint 对分支依赖很弱；微小的分数上升不能作为“关闭模块更好”的可靠证据。

当前公式 `F' = F × (1 + α × tanh(Conv(prior)))`，训练时 α=0.1。实测平均绝对调幅约 0.7606%，空间标准差约 0.3920%，最大观测绝对调幅约 4.8529%。先验本身不是零或常量。首 32 张验证图抽样中，梯度与 3×3 方差通道相关系数约 0.948。

证据支持的结论与尚待验证的解释：

- 已确认：M1 仅在四尺度平均融合之后做弱乘性调整，不改变尺度选择；调制器只读取四个灰度先验通道，不直接读取语义特征。
- 已确认：当前训练结果对调制和先验空间信息都不敏感。
- 待验证：后续 Conv + GroupNorm 可能削弱部分近似统一的缩放；先验间相关性、与骨干纹理信息重叠、降采样和裁剪/整图归一化差异也可能影响收益。不能把这些假设直接认定为 bug 或主因。
- 日志采样点约 97% 触发梯度裁剪，两组一致；仅凭这一点不能认定 M1 没有学到参数。

完整诊断见 [analysis.md](logs/m0_m1_diagnosis/analysis.md) 和 [原始干预指标](logs/m0_m1_diagnosis/m1_validation_interventions.json)。

## 5. 调制系数 α 快速扫描

2026-09-20 在 server2 完成。先做 2 张验证图的 smoke test，再用同一个 M1 best.pt 对完整 699 张验证图扫描六个系数。完整扫描约 49.69 秒，720,766,068 个有效像素，原分辨率、FP32、无 TTA，未更新 checkpoint 权重。

| α | Val mIoU (%) | Boundary F1 (%) | 相对 α=0.1 改变预测的有效像素 (%) | 平均绝对调幅 (%) |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 76.791874 | 13.189388 | 0.03326 | 0 |
| 0.1 | 76.789540 | 13.199341 | 0 | 0.7606 |
| 0.3 | 76.784226 | 13.214531 | 0.06784 | 2.2817 |
| 0.5 | 76.776493 | 13.227166 | 0.13699 | 3.8028 |
| 1.0 | 76.748582 | 13.243445 | 0.31645 | 7.6056 |
| 1.5 | 76.707764 | 13.238715 | 0.50610 | 11.4083 |

固定当前权重时，增大 α 未提升 mIoU，α=1.5 较 α=0.1 下降约 0.0818 个百分点；边界 F1 有小幅变化，不代表整体分割精度同步改善。扫描正常结束，未发生非有限 logits 错误。

理论上特征乘数在 `1−α` 到 `1+α` 之间：α=0.5 保持正值；α=1.5 允许零值或负值，但理论允许不意味着本次实际发生了符号翻转。增大 α 不必然导致数值崩溃，也不保证增强有用信息。

这是已训练权重的推理敏感性检查，不能代替新系数的训练实验。若要正式比较，应从相同骨干预训练初始化和相同种子、预算重新训练；从现有权重微调则需单列实验，并重新安排学习率。现有训练器尚未提供用于正式训练的 α 命令行/协议配置，诊断接口不等于完成了新 α 训练支持。

脚本：[diagnose_modulation.py](diagnose_modulation.py)；结果：[JSON](logs/m1_seed3407/modulation_diagnostic.json)、[日志](logs/m1_seed3407/modulation_diagnostic.log)。脚本默认扫描 0、0.1、0.3、0.5、1.0、1.5，默认 val。`mean_max_abs_delta` 是逐图最大调幅的平均值，不是全数据集绝对最大值。

### 6.3 当前结论与后续验证顺序

当前单种子结果支持“动态尺度融合改变了精度取舍，先验没有带来可观测的额外 mIoU 收益”。M2 是按验证集表现应保留的动态融合候选；M0 是必要的简单基线，且本次 test mIoU 数值最高。四组 test mIoU 总跨度仅 0.120052 个百分点，尚无多种子或逐图不确定性分析，不能作统计显著性的优劣判断。也不能将数学先验在这两种实现中的无收益推广为所有先验方案无效。

后续优先在验证集进行 M3 的先验置零、空间均值替换、空间打乱干预，并同时记录尺度权重变化和预测变化，区分“先验没被使用”与“使用后没有收益”。随后分析验证集裸地/农业地的失败图，检查 gate 的空间变化；正式改进用多个配对种子复核 M0/M2 与 M2/M3。现有 test 结果作为本轮离线报告，不用于调参。M4 的类别重加权可检验类别取舍，但本次结果尚不能证明它会修复裸地漏检。本次仅分析已有日志，未启动上述新实验。
