# M0/M1 无提升诊断

## 结论

已核对本地/服务器模型、训练、协议脚本 SHA256 一致，核对两组实际 checkpoint 和优化器，并用 M1 best.pt 在完整验证集做推理干预。

未发现加载错模型、漏优化调制参数、数据划分不一致等运行错误。当前更有证据支持的解释是：M1 的先验调制对最终预测影响很弱，尤其没有表现出对先验空间结构的有效依赖。不能据此断言所有数学先验方案都无效。

## 原实验

| 指标 | M0 | M1 | M1−M0（百分点） |
| --- | ---: | ---: | ---: |
| 最佳 Val mIoU (%) | 76.803343 | 76.789540 | -0.013803 |
| Test mIoU (%) | 77.808509 | 77.804144 | -0.004365 |

两组最佳 checkpoint 都是 update 159600。共有 58 个验证点，M1 在其中 11 个点高于 M0，验证差值范围 -0.048475～+0.024206 个百分点。差异在中断恢复之前已经存在；没有证据将本次结果归咎于恢复训练。

两组配置除 variant、work_dir 外一致：MiT-B3、width=64、seed=3407、512 裁剪、batch=2、160000 updates、FP32、AdamW、骨干初始 lr=1e-5、其余 lr=1e-4、weight_decay=0.01。val_size=0；验证和测试均原分辨率。固定 train/val/test 划分哈希一致；不以 test 选择 checkpoint。代码忽略标签 0，以累计混淆矩阵计算类别 1..8 的 IoU。

这些检查确认文件名级划分互斥及协议一致，不等于已经证明不同划分不存在同场景/相邻帧相关性。

## 实际权重与优化状态

- M0 总参数 44,212,554；M1 总参数 44,212,874，只增加 320 个参数。
- M1 调制权重范数 1.001925，bias 范数 0.198081；不是始终为零。
- 调制 weight/bias 的 Adam step 都是 159600，exp_avg 和 exp_avg_sq 非零；优化器确实包含这两个参数。
- 两组共有的所有可学习参数张量均非逐位相同。编码器相对 L2 差异约 0.000795，投影约 0.006419，解码器约 0.004760；不是同一份权重重复测试。

## 完整验证集干预（699 张）

同一 M1 best.pt，复用编码器和对齐特征，只改变调制路径。正常路径复现原 best validation mIoU 的精确值。没有更新权重。

| 模式 | Val mIoU (%) | 相对正常路径改变预测的有效像素 (%) |
| --- | ---: | ---: |
| 正常 M1 | 76.789540 | 0 |
| 完全旁路调制，直接使用融合特征 | 76.791874 | 0.033255 |
| 每个先验通道替换为该图空间均值 | 76.790021 | 0.016213 |
| 先验置零，保留调制卷积 bias | 76.790865 | 0.029243 |

关闭调制的 +0.002334 个百分点非常小，不能当作可靠的“关闭后更好”结论。更有用的观察是：关闭调制几乎不改变结果，移除空间信息也没有可见的精度损失。

令 delta = 0.1*tanh(Conv(prior))：

- 全验证集按图平均的 mean(abs(delta))：0.007605565，即平均绝对特征调幅约 0.7606%。
- 按图、按通道计算空间标准差再平均：0.003919939，即约 0.3920%。
- 全部观测到的最大 abs(delta)：0.048529010，即约 4.8529%。
- 对齐后先验本身的平均空间标准差约 0.20695，并非输入先验全部为零或常量。
- 首 32 张验证图抽样的 gradient/variance3 相关系数约 0.948；其余通道也存在较高相关性。此为抽样相关性，不足以单独证明先验冗余就是主因。

## 设计层面的解释与尚未验证的假设

1. **已确认的限制：作用弱且位置较晚。** M1 只在四尺度平均后，执行 4→64 的 1×1 卷积乘性调制，系数限制为 0.1；实际平均调幅不到 1%。它不能改变各尺度的融合比例。诊断表明当前训练结果几乎不依赖这次调制。
2. **已确认的限制：调制器不读取语义特征。** 它只接收四种灰度边缘/纹理响应，不能直接依据语义区分物体边界和内部纹理。数学先验对任务是否有额外帮助，仍需更合适的条件融合对照。
3. **合理但未证实：后续解码器可能吸收部分调幅。** 调制紧接 Conv + GroupNorm。接近统一缩放的部分可能被归一化削弱，通道和空间变化不会被完整消除，不能把 GroupNorm 直接认定为 bug 或声称它消除了所有调制。
4. **合理但未证实：先验存在信息重叠和尺度问题。** 灰度先验可能与骨干已有边缘/纹理特征重叠；先验双线性降至 1/4 分辨率、按图均值归一化，可能影响细边界和训练裁剪/整图推理的一致性。尚无干预结果证明这些是主要原因。
5. **实验结论范围有限。** 只有 seed=3407，不能估计跨随机种子的方差。M0 是本实验受控基线，不是完整原 HyperSeg；M1/M0 只检验融合后弱乘性调制，不检验 M3/M2 的数学先验尺度选择。

日志抽样点约 97% 触发全局 grad clipping。两组一致，且 AdamW 下不能仅凭裁剪频率断言新分支学不动。本次已有非零权重与优化状态，也不支持“参数完全没训练”的解释。

## 建议顺序

1. 保留 M0/M1 为当前实现的近似持平结果，不因没有提升就判定消融无效。
2. 下一优先项是预先定义的 M2/M3 配对实验：语义尺度 gate 与语义+数学先验尺度 gate，保持参数规模、初始化和预算可比。它更直接测试方案中的核心尺度选择假设；并不保证一定提升。
3. 若继续研究 M1，先在验证集做单因素短程试验，例如残差强度、语义条件输入或加入加性残差；这些都属于新变体，需要独立训练与命名。直接放大已有 checkpoint 的调制只适合作为敏感性诊断。
4. 给后续实验增加 prior 分布、调制/gate 幅度、分支梯度、分项 loss 记录；只存总 loss 和最终 mIoU 难以解释模块贡献。
5. 正式论证方法收益时，至少做 3 个配对种子，报告均值和标准差。后续选择以验证集为依据，固定 test 保留用于最终报告。

原始诊断数据见 m1_validation_interventions.json。本次仅分析和推理诊断，未修改模型/训练实现、未启动新训练。
