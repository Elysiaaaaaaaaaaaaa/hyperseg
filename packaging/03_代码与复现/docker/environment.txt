Notes
-----
* CPU quota of the container in no-GPU mode is 0.5 core with 2 GiB RAM. torch
  defaults to one thread per visible core (128 here) and thrashes badly under that
  quota: the same preflight takes 15 s with OMP_NUM_THREADS=2 and about 4 min with
  the default. Always export OMP_NUM_THREADS when running without a GPU.
* transformers is pinned to 4.x. `models/hyperseg_b3_best.pt` was written by a
  transformers 5 release, so its backbone keys need translation before loading;
  hyperseg_uav.model.translate_legacy_keys does that (628 keys).
